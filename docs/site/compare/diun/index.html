HarborBuddy vs Diun

Diun tells you when a Docker image has an update. HarborBuddy applies the update and rolls it back if the new container fails. They solve different problems, and they work well together.

Run both

A common setup: HarborBuddy updates stateless services automatically, databases carry the opt-out label, and Diun notifies you about every image so you can update the excluded ones by hand.

services:
  postgres:
    image: postgres:17
    labels:
      com.harborbuddy.autoupdate: "false"   # HarborBuddy skips it
      diun.enable: "true"                   # Diun still notifies you

FAQ

Does Diun update containers?

No. Diun (Docker Image Update Notifier) only sends notifications when an image changes. It never pulls images into running containers or recreates them.

Can I use Diun and HarborBuddy together?

Yes. They do different jobs. Let HarborBuddy update the containers you trust, exclude sensitive ones with com.harborbuddy.autoupdate=false, and let Diun notify you about everything, including the excluded containers.
