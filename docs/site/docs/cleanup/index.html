Cleanup

Clean up old images and unused resources

Updates leave old images behind. By default HarborBuddy removes dangling images older than 24 hours and nothing else. Broader cleanup is opt-in, one category at a time, and never touches anything in use.

What can be cleaned

CategorySettingDefault
Dangling (untagged) imagescleanup.enabledOn
Unused tagged imagesdangling_only: falseOff
Stopped containersstopped_containersOff
Unused local networksunused_networksOff
Unused volumesunused_volumesOff
Build cachebuild_cacheOff

all: true (HARBORBUDDY_CLEANUP_ALL=true) turns on every category. Individual switches are safer on shared hosts. Preview candidates with dry-run first: unused-volume cleanup can permanently delete application data.

What is never removed

  • Images used by any container, running or stopped, and images other images are built on.
  • Networks any container is attached to, and system networks.
  • Volumes any container references.
  • Stopped containers with a restart policy (always, unless-stopped, on-failure), such as a stopped Compose service. Only stopped containers with policy no are removed.
  • HarborBuddy's own update backups and self-update helper records.
  • After a failed or rolled-back update, the affected container and its volumes for that cycle.
  • Anything whose age or usage Docker cannot report.

Keep rules

cleanup:
  keep_images: ["ghcr.io/org/tool*"]       # same syntax as allow_images
  keep_volumes: ["*-backups"]              # volume-name globs
  keep_volume_labels: ["com.example.keep=true"]

keep_images is for images only host tools run, such as a docker run --rm helper, which otherwise look unused between runs. Patterns match tags, digest references, and the repository of a digest reference.

Ages

min_age_hours (default 24) applies to everything. Untagged images and cache volumes can expire sooner with dangling_image_min_age_hours, and cache_volumes with cache_volume_min_age_hours. For containers, networks, and volumes, age means time since creation, not time since the resource became unused.

Run cleanup on its own

docker run --rm --no-healthcheck \
  -v /var/run/docker.sock:/var/run/docker.sock \
  ghcr.io/mikeo7/harborbuddy:0.1 --cleanup-only --dry-run

Drop --dry-run to delete what it reports.
