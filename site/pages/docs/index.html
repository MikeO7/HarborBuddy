HarborBuddy documentation

HarborBuddy is a self-hosted service that keeps the containers on a standalone Docker Engine up to date. It pulls each container's image reference, compares image IDs, and replaces a container only when the image changed. The original stays as a backup until the replacement is ready, so a bad image gets rolled back instead of left broken.
